HQ Recorder - Android screen recorder (4K / 2K / 1080p / 720p, 30/60 fps, game sound + mic)

APK banane ke 2 tarike:
1) Android Studio (PC): File > Open > is folder ko kholo > Build > Build APK(s).
2) PC nahi hai to: is folder ko GitHub repo me upload karo > Actions tab > "Build APK" > Run workflow
   > finish hone par "HQRecorder-apk" artifact download karo (andar app-debug.apk milegi).

Minimum: Android 10 (API 29).
